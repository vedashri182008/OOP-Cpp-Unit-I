## 💻 Programs

This repository contains **8 practical programs** based on basic C++ programming and fundamental Object-Oriented Programming concepts.

### 01. Basic Data Types

Demonstrates the use of basic data types such as `int`, `char`, and `float` to store and display student information.

### 02. if-else

Demonstrates the use of an `if-else` statement to check whether a student has passed or failed based on marks.

### 03. Loop and Array

Demonstrates the use of an array and `for` loop to store and display the marks of five students.

### 04. Functions

Demonstrates the creation and use of a function with a function prototype to perform addition of two numbers.

### 05. Class and Object

Demonstrates the use of a class and object to store and display student details using data members and a member function.

### 06. Constructor and Destructor

Demonstrates automatic object initialization using a constructor and object cleanup using a destructor.

### 07. Static Member

Demonstrates the use of a static data member to count the number of objects created from a class.

### 08. Inline and Friend Function

Demonstrates the use of an inline getter function and a friend function to access private data of a class.
